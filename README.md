# Folio

Folio is a personal Android media library application currently under development.

## Project Overview

Folio helps users organize their personal collections of books, anime, manga, and TV series. The application is designed to manage media metadata locally on Android devices.

## Planned TMDB API Usage

Folio intends to use the TMDB API to retrieve movie and TV metadata, including titles, synopses, cast information, and poster images.

The API will be used for metadata lookup, data integration, and development testing.

## Project Status

Folio is currently under development. The source code is maintained in a private repository and is not included in this public project overview.

## Attribution

This product uses the TMDB API but is not endorsed or certified by TMDB.
